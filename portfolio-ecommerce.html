// 01. CONTEXT & CHALLENGE

撕除環保包裝的廉價說教標籤

植物奶與冷萃咖啡近年在全球快速普及，但市場上的永續包裝設計經常走向兩極：要麼過度簡陋而失去精品價值，要麼過度包裝造成資源浪費。

本專案旨在探索一種兼顧「環境責任」與「高端生活格調」的視覺平衡：透過手繪植物線條、大地色系與未塗布紙質模擬，在實體紙盒與線上選購介面中營造溫潤沉靜的自然氛圍。

// 02. CREATIVE DIRECTION & DESIGN SYSTEM

大地色系與手感線條語彙

COLOR PALETTE

深森林綠、大地石灰與冷杉淡綠，傳遞純淨自然植感。

TYPOGRAPHY
Editorial Serif + Clean Sans

以高對比現代襯線標題搭配純淨內文，建立生活誌閱讀節奏。

PROPOSED MATERIAL DIRECTION
Uncoated Paper Direction

以未塗布再生紙材為概念方向，探索自然觸感與編輯式排版的包裝視覺。

// 03. PACKAGING DESIGN ARTIFACTS

實體紙盒與易開罐包裝概念模擬

純素冷萃低碳咖啡包裝概念展示 [PACKAGING_CONCEPT]

設計探索包含單罐易開鋁罐包裝與外層折疊紙盒。紙盒外觀以柔和的大豆油墨色澤印製手繪燕麥線條，側邊標註低碳原料來源說明，呈現兼具環保初衷與貨架吸引力的陳列視覺。

// 04. CORE CAPABILITIES DEMONSTRATED

本專案展示之核心專業能力

01. 永續品牌定位與美學詮釋

能為環保與綠色生活品牌提煉高品質的視覺基調，避免落入廉價粗糙的俗套。

02. 實體包裝紙質與印刷概念推演

掌握未塗布紙張、大豆油墨與印刷顯色特徵，在概念階段即可精準預判實體觸感與視覺效果。

03. 編輯生活感版面排版

善用留白、行距與字體粗細對比，打造具備雜誌感的生活消費品電商與形象視覺。

04. 品牌敘事與感性共鳴構建

結合圖文韻律傳遞產品原料與永續主張，讓包裝成為品牌無聲但強大的溝通介質。
